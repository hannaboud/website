The project

A data center runs two kinds of AI work. Always-on work, like answering chatbot requests, has to run the moment it arrives. Flexible work, like batch jobs, can wait, as long as it finishes before its deadline. Electricity prices change every hour, so flexible work that waits for cheaper hours costs less.

The scheduler is a linear program. Each week it plans when to run the flexible work using day-ahead prices, which are published in advance, and then pays the real-time prices that actually happened. I tested it on a 1 MW data center block over 48 weeks of hourly prices in two markets: Virginia (PJM, Dominion zone) and Texas (ERCOT, North hub), and compared it with simpler rules: running work immediately, running it at a fixed time of night, planning on typical prices from the past four weeks, and a perfect-hindsight upper bound.

How the agent works

The agent is Claude (Anthropic's model) running in a loop I wrote by hand, so every step can be explained. It never answers from memory. To answer a question it:

  • Calls tools that look up precomputed weekly results: yearly and seasonal totals, single weeks such as the winter storm, and the best fixed time-of-day window.
  • Uses a calculator tool for every difference or percentage, instead of doing arithmetic itself.
  • Passes a number check before you see the answer: code confirms that every number in it appears in a tool result. If one doesn't, the agent gets one chance to fix it.

Tested before it went online

I wrote 30 questions whose correct answers are computed directly from the results files, including two it should decline (a market and a month that aren't in the data). The agent scored 30/30 on accuracy, exact match and grounding.

What it can and can't see

The website only has the precomputed weekly results. The raw hourly price data never leaves my laptop, and a privacy guard in the code rejects any tool result that isn't a single number or a short label, so a price series can't be sent anywhere. Each visitor has a spending limit, and the demo has a monthly budget.
